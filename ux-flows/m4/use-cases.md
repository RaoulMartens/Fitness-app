# M4 - UC-010 onboarding en eerste plan

De gebruiker autoriseert de bestaande UC-010 met 'ga verder met m4'. Geen nieuwe use case.

| Onderdeel | Uitwerking |
| --- | --- |
| Actoren | Gebruiker, lokale app |
| Voorwaarde | Nog geen geaccepteerd voorbeeldplan; bestaande intake mag ter controle zijn voorgevuld |
| Hoofdpad | Start, doel, ervaring, week, context, voorstel, Zo beginnen, Vandaag |
| Alternatieven | Lege intake; terug met behoud van invoer; antwoorden wijzigen vanuit voorstel; compromis bij 45 minuten; niet ondersteunde context |
| Foutpad | Ontbrekend antwoord blijft bij de vraag; opslagfout bewaart zichtbare invoer en blokkeert volgende stap; onleesbare opslag wordt niet stil vervangen |
| Na bevestiging | Geaccepteerd voorbeeld en week zichtbaar; conceptwijzigingen veranderen het geaccepteerde voorbeeld niet |

Bij een compromis wordt geen optie vooraf gekozen. De gebruiker kan meer tijd toestaan of zijn
randvoorwaarden behouden. In het laatste geval volgt geen nep-plan. Een optionele weekendtraining
ontstaat alleen door een keuze. Concept, geaccepteerd plan en bestaande hoofdapp blijven gescheiden.
